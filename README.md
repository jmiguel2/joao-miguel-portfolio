# João Miguel — Portfólio

Primeira implementação baseada no Manual Técnico de Design do portfólio.

## Estrutura

- `index.html` — conteúdo e estrutura
- `css/` — reset, tokens, base, componentes, seções e responsividade
- `js/main.js` — menu mobile e reprodução dos vídeos
- `assets/images/` — imagens
- `assets/videos/` — vídeos

## Assets esperados

Adicionar os arquivos reais nos caminhos usados pelo `index.html`.

A implementação não inventa arquivos de mídia: os nomes são placeholders estruturais para serem substituídos pelos arquivos finais.
